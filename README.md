# todo: A To-Do List API

This is a Python project which exposes an API backend for a simple to-do list application.

It uses FastAPI with a SQLite database to store and manage to-do list items.

## Installation
This is not currently an installable Python package. 
Despite this, you will need a tool called `pixi` to manage the Python environment.

`pixi` is a commandline tool used to manage Python environments with dependencies from both `conda` channels and PyPI, and define task execution (like Make).
If it is not already available on your system, please follow the instructions at https://pixi.prefix.dev/latest/installation.

The easiest way to install `pixi` on Linux/MacOS is:
```
$ curl -fsSL https://pixi.sh/install.sh | sh
```

## Quickstart
Once `pixi` is available, clone this repo and launch the API from your commandline:
```
$ git clone https://github.com/kaedonkers/todo.git
$ cd todo
$ pixi run start --gui
```
By default, this will run the API at `http://localhost:8000/`, where it will listen for requests.
The `--gui` option will launch an interactive user interface in a browser at `http://localhost:8000/docs`, giving you a dashboard for monitoring and interacting with the API.

### API Documentation
Generative documentation can be accessed when starting the server using the `--docs` flag:
```
$ pixi run start --docs
```

### Commandline options
Here is a list of the available options to start the server with:
```
$ pixi run python start.py --help
usage: start.py [-h] [--host HOST] [--port PORT] [--gui] [--wait WAIT]

Start the todo server, with optional UI

options:
  -h, --help   show this help message and exit
  --host HOST  Host to run the server on
  --port PORT  Port to run the server on
  --gui        Open server GUI in the browser
  --docs       Open server documentation in the browser
  --wait WAIT  Seconds to wait for server to start before opening browser
```

## Testing
Tests are run using [`pytest`](https://docs.pytest.org/en/7.1.x/getting-started.html).
To run the full test suite, execute the following:
```
$ pixi run tests
```
Run tests with more information by using the verbosity flag `-v`:
```
$ pixi run tests -v
```
Information on how to run `pytest` CLI can be found in the documentation: https://docs.pytest.org/en/latest/how-to/usage.html
